# 每日行程讲解（预览）

用户在地图选择一天，点击「每日行程讲解」，或通过 Agent 的文字、语音对话要求逐站讲解。

模型先读取最新行程，再用 `day_narration` 一次生成分段稿件。第一段和最后一段展示全天，中间按活动顺序逐站介绍，可插入双点转场。每段绑定已保存的真实地点 ID；备选、待定位和未核实时间须在稿件中明确，不补造坐标或交通信息。

播放器依次执行：地图展示回执 → 准备中文系统语音 → 播放 → 音频结束 → 下一段。单点沿用地点详情弹窗，双点展示转场，待定位活动回到当天地图。地图展示和朗读不会修改旅行安排。

控制入口使用现有默认组件：上一段、暂停、继续本段、下一段、结束，以及可展开的讲解文字。暂停后的继续从当前段开头播放。手动地图操作、切换页面、关闭跟随、用户插话或新消息排队均暂停；显式继续可恢复地图跟随。行程内容变化后旧稿失效，需结束并重新生成。

文字与语音共享同一工具。实时通话期间讲解播放会静音远端输出，保留麦克风用于打断；打断后恢复通话输出。系统 TTS 在主进程生成，界面通过本地 Blob 播放，临时文件与播放 URL 用完即释放。

当前范围：macOS 中文系统语音；讲解稿不持久化；生成稿件后自动播放；音频按段生成并在本次讲解中缓存最近八段。其他系统会显示当前语音能力限制。此版优先验证逐站讲解体验，后续可优化声线、预加载、稿件编辑与中途问答后的续播位置。

验证覆盖：真实 Electron 下按钮请求、系统音频播完后的地图推进、单点详情、双点转场、暂停与旧回调隔离、跳段、关闭跟随、行程更新、实时语音工具调用及排队提问中断。
