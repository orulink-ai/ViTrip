# 笔记目录与阅读体验

笔记选择从下拉框改为可搜索目录。工作区宽度达到 760px 时默认显示右侧目录，用户可以收起；更窄时通过“目录”按钮打开官方 Sheet 抽屉，选择后关闭。目录只展示当前旅行的独立 Markdown 文档和随手笔记，不暴露资源附件。

当前笔记使用默认 secondary 按钮样式和 aria-current 标记；标题隐藏 .md 后缀，悬停保留完整文件名。搜索按文件名过滤，空结果有明确提示。新建文档自动补齐 .md；另存为进入更多菜单。正文顶部固定显示标题、保存状态和编辑/新建/目录操作，避免多层重复工具栏。

按旅行和文档在 sessionStorage 保存阅读滚动位置。切换笔记或关闭再打开工作区时恢复阅读位置；跨旅行隔离。聊天里的笔记入口清除搜索条件并打开指定笔记；原有编辑草稿和版本保护继续沿用。

只使用现有 shadcn Button、Input、DropdownMenu、Sheet 进行业务装配，保持官方中性色样式。当前是平铺目录，没有引入文件夹分类、删除或重命名功能。

## 展开笔记工作区

笔记页增加与行程页一致的展开/恢复按钮。展开后正文占满主工作区，聊天使用现有 AssistantModal 悬浮窗，支持移动、缩放、收起和再次打开。展开状态与用户手动选择的浮动聊天偏好独立，恢复布局时沿用原偏好；点击“停靠聊天”或关闭工作区会退出展开。聊天笔记卡片跳转保留展开状态。

展开模式保留聊天草稿与笔记编辑状态。浏览器标签仍遵守原有原生页面约束，临时停靠聊天，返回笔记后恢复浮动。没有修改系统窗口的全屏状态。

隔离构建通过；笔记展开、目录切换、浮动聊天和地图展开共4项 Electron 用例通过。

## 标记的双向链接

聊天中“标记到笔记本”成功保存后，原文对应字符显示用户指定的蓝色下划线，鼠标点击或键盘 Enter/空格打开笔记本。按旅行/会话/消息匹配持久化标记，在 Markdown 渲染树上装配交互，保留原有加粗、链接等结构。新选区保存前后文锚点辅助定位，旧标记仍按原文匹配。

打开标记会切换到随手笔记、展开标记列表、滚动并聚焦对应条目。条目常驻“回到原文”文字入口，返回对应会话并聚焦原文片段；取消标记后原文装饰同步移除。只有实际保存成功才添加下划线和跳转；原始聊天内容不改写。

新增单元测试覆盖空白归一化、跨格式字符偏移和上下文匹配；Electron 用例覆盖从其他笔记切换到标记、蓝色下划线、双向定位、键盘入口、重启恢复和取消标记。原引用回归断言更新为聚焦具体标记片段。

## 文件夹层级（2026-09-29）

- 目录对应旅行 notebook 下的真实文件夹；支持多级路径、空文件夹、新建子文件夹、搜索完整路径。
- 笔记和文件夹可拖入目录，根目录也是放置目标；笔记的更多菜单提供“移动到文件夹”。
- Agent 的 notebook 工具支持 list_folders、mkdir、move；write 支持相对路径并创建父目录。长期规则要求优先沿用用户分类。
- 移动拒绝重名覆盖、过期笔记版本、目录移入自身及越界路径；未保存草稿会阻止界面移动。
- 移动记录保存在 notebook/.moves.json，旧聊天入口解析到新位置。本地图片仍共用 notebook/assets，读取移动后的笔记时按新目录深度修正 Markdown 相对引用。
