# 行程地图外观

地图工具栏的「地图外观」可即时切换六种底图：经典街道（OpenStreetMap）、Liberty、Bright、Positron、Dark、Fiord。后五种使用 OpenFreeMap 官方样式，无需用户配置访问令牌；这些并非 Mapbox 的 Default、Faded、Cool 原版，也不包含卫星影像。

视角支持平面、倾斜和可拖动旋转的地球。地球模式缩小至全球视野，点击地点或地点簇可以重新拉近；「查看全部地点」恢复平面行程全貌。倾斜视角的建筑高度效果取决于官方底图与当前缩放级别，经典街道仅为二维影像倾斜。

外观按旅行保存在本机，不按日期拆分；日期筛选、地点选择和行程数据独立于底图。可把当前外观设为尚未保存偏好的旅行的默认值。视野仍按旅行与日期分别保存。现阶段选择按钮提供即时地图预览，尚未提供离线缩略图画廊。

底图切换请求可以取消，避免快速切换时旧请求覆盖新选择。样式下载失败保留旧底图并提示重试。样式加载后重建行程图层，保留地点选择；底图失败时地点列表仍可使用。外部网络白名单仅增加 tiles.openfreemap.org，地图资源不需要接触主进程密钥。
