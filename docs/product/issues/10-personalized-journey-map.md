# 个性化行程地图：路线、地点与当天安排联动

## 问题与目标

当前地图已有地点与行程双向定位，但需要让使用者一眼读懂自己的整趟旅行。参考用户提供的 Roadtrippers 截图：列表和地图共享编号，路线形成主线，地点按类别区分，重要地点带照片，沿途候选保持可探索性。

参考：[Roadtrippers](https://roadtrippers.com/)。结合 Mindtrip 风格的行程工作区，形成“每天怎么安排”和“空间里如何移动”两个视角。个性化来自用户的真实安排、住宿、交通偏好与关注点。

## 范围

- 全程视图突出主要停留城市、住宿与跨城市移动；当天视图突出当日站点与顺序，弱化其他日期。
- 列表与地图共享编号和稳定地点 ID；选中任一侧时另一侧同步定位、展开相关详情。
- 住宿、餐饮、景点和交通使用一致的类别图标；只有重点或选中地点展示照片标签。
- 缩小时聚合密集标记，避免照片与标签遮挡；地图展开、收起后保留视角和选择。
- 已安排地点、互斥备选与沿途推荐有明确区别。推荐围绕用户住宿、交通与兴趣，显示推荐理由；未经选择不自动加入必走路线。
- 使用 MapLibre 现有基础；无坐标时保留待定位，区域参考点不能冒充精确目的地。
- 有可靠导航服务数据时显示实际路线、交通方式、距离与耗时；否则明确标注为行程顺序连线。

## 验收

- [ ] 全程与当天视图切换后，编号、选择和行程条目对应正确。
- [ ] 跨日、住宿重复引用、备选地点和密集站点场景不会画出误导路线。
- [ ] 地图照片与行程照片使用同一资料记录，支持来源查看。
- [ ] 偏好变化会影响候选内容或推荐理由，而不是只改变配色。
- [ ] 无坐标、无图片、底图网络失败时仍可操作地点列表。
- [ ] 真实 Electron 交互和重启恢复测试通过；在线瓦片、路线数据另行验证，不用模拟瓦片证明在线可用。

## 实现边界

沿用默认中性 UI，用编号、图标、大小、选中态与信息取舍建立层级；不以装饰插画或全图照片堆叠替代可读性。地图路线、耗时和照片必须保留数据依据。无需在本期实现道路导航或商业预订。

依赖：行程工作区、真实照片采集与来源记录；实际道路路线需要另行选择数据服务。
