# feat: AI 旅行日记、视频生成与社媒分享

状态：本地草稿，尚未创建 GitHub Issue。
记录日期：2026-09-27。
建议阶段：P1 文字与导出；P3 视频及更多分享集成，待讨论。

## 目标

让用户将旅途记录整理为可编辑、可分享的文字作品，后续扩展完整旅行视频。

## 范围

- 选择旅行、记录和素材，一键生成文字日记或日志草稿，支持修改与版本保留。
- 区分实际经历、仅有计划和 AI 补写；不将未发生的行程写为亲历。
- 后续支持素材排序、视频草稿预览与导出，明确音乐、图片和素材的使用权。
- 生成任务支持进度、取消、失败重试与费用提示，原始记录不被覆盖。
- 先提供素材导出与系统分享；小红书、抖音直接发布需实际接口能力验证和用户明确发布操作。
- 分享前预览敏感内容与素材范围；私密订单、证件和精确定位不自动进入公开作品。

## 验收场景

- 仅选择部分记录时，生成结果可追溯到选定素材，未选择的私密素材不进入输出。
- 只有规划、没有旅行记录时明确提示素材不足或生成计划介绍，不虚构亲历。
- 用户编辑草稿后重新生成不会静默覆盖编辑版本。
- 导出可正常打开；不支持直接发布的平台展示可用替代路径，不虚报发布成功。
- 视频阶段另行验收取消、失败恢复、预览一致性与可播放的成片。

## 依赖与边界

依赖地点记录和素材管理；文字与视频应分阶段实施。

## 待讨论

首期默认日记风格、长度和导出格式是什么？视频时长、预算与分享平台优先级如何安排？
