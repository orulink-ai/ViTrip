## 组件决策

- MapAnswer 是 0–100 百分比定位的示意网格，不使用真实地理投影，不能替换主行程地图。
- GeoMap 使用 Leaflet，默认对 OSM 瓦片灰度化；通过可信的应用配置传入 tileUrl，可按瓦片原色显示。它适合对话中的少量地点结果。
- GeoMap 当前源码没有提供现有行程所需的聚合、按日视角保存或 3D 建筑/地形配置。直接替换会需要重新实现这些能力。
- 主行程地图建议保留 MapLibre。地图本身也是成熟开源组件；面板、日期切换、照片和操作按钮继续采用 assistant-ui Elements / shadcn。用户本次明确提出的地图颜色与立体感，作为地图信息编码的设计要求。
- 真实建筑立体效果需要带建筑轮廓/高度的矢量数据；真实地形需要高程数据。仅倾斜平面瓦片不能宣称是三维地图。

## 三轮设计收敛

以下是迭代目标，不能当作已实现后的评分。

1. 识别优先（目标 7.5/10）：简洁彩色底图，当前日与其他日区分；直接显示重点地点名称；酒店固定作为住宿参照；明确加载态及「查看当天全部地点」操作。否决仅给所有图钉换鲜艳颜色的方案，它仍要求反复对照编号。
2. 行程优先（目标 9/10）：宽视图采用行程列表与地图并排，窄面板保留地图和可见的当前地点摘要；日期直接可见；选列表高亮地图、选地图定位列表。照片仅来自已有来源数据，密集区域聚合，选中地点露出完整名称和详情。地图缩放时不要所有照片、名称同时展开。
3. 空间体验（目标达到下述验收标准）：默认平面便于规划，提供可选倾斜/立体视图、一键回正和路线总览；有数据才显示建筑/地形。保留减少动态效果选项，并验证低性能设备及无网络时的可用性。

## 10/10 的验收定义

不能靠反复自评宣称满分。实施后至少完成下列用户任务，再进行复评：

- 第一次打开，能在 5 秒内指出正在看的日期、住宿与第一站；以实际走查测量，不预填结论。
- 能通过名称识别地图地点，不必记住数字；颜色之外仍有日期、编号、类别文字。
- 一次选择即可在地图与行程中确认同一个地点；详情不遮住该地点。
- 拖动或进入倾斜视图后，一次操作恢复当天全貌；切换视图不意外丢失选择。
- 密集地点、重复住宿、跨城行程、无照片、未知坐标、离线都能完成基本查看。
- 顺序连线与真实导航路线明确区分；没有真实路线数据时不提供伪造的车程/路程。
- 窄窗口、键盘操作、色觉差异及减少动态效果场景通过验证。
