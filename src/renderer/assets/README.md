# 首页地图背景

`home-map-tilted.png` 复用 `artifacts/map-appearance/audit/liberty-tilted.png`：现有 MapLibre / OpenFreeMap Liberty 倾斜立体视角的真实地图截图，地点为京都。首页通过 CSS 裁切中间地图区域，隐藏截图中的顶部与底部控件，灰度并渐隐显示；它不是用户足迹数据。

地图数据及底图署名：© OpenStreetMap contributors / OpenMapTiles / OpenFreeMap。首页和展开地图保留署名。截图来源记录见 `scripts/check-map-appearance.mjs` 与 `artifacts/map-appearance/audit/results.json`。
